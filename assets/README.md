# 마스코트 이미지 넣는 곳

토끼 마스코트 PNG를 **이 폴더에 아래 이름 그대로** 올리면
`index.html`이 자동으로 불러옵니다. 코드는 손댈 필요 없습니다.

| 파일 이름 | 어떤 컷 | 페이지 안 위치 |
|---|---|---|
| `mascot-basket.png` | 채소 바구니를 안고 있는 토끼 | 히어로 우측 (가장 크게) |
| `mascot-carrot.png` | 당근을 타고 나는 토끼 | 채소 룰렛 캘린더 오른쪽 아래 구석 |
| `mascot-jump.png` | 포크를 들고 점프하는 토끼 | 주간 리포트 완성 축하 카드 |
| `mascot-run.png` | 선글라스를 쓰고 달리는 토끼 | 푸터 브랜드 정보 옆 |

## 규칙

- 네 개를 다 채울 필요는 없습니다. **올린 것만 화면에 나오고,
  없는 파일 자리는 자동으로 비워집니다.** (히어로 자리는 파일이 없으면
  임시 샐러드 볼 일러스트가 대신 보입니다)
- 배경이 **투명한 PNG**여야 합니다. 흰 배경이면 크림색 화면 위에
  네모난 흰 판이 보입니다.
- 가로 세로 각각 600–1200px 정도면 충분합니다.
  파일 하나당 500KB 아래로 맞춰주세요.

## 올리는 방법 (GitHub 웹)

1. 이 폴더 화면에서 오른쪽 위 `Add file` → `Upload files`
2. PNG 파일을 끌어다 놓기
3. 아래 `Commit changes` 클릭

파일 이름이 위 표와 다르면 GitHub 업로드 화면에서 바꿀 수 없으니,
**컴퓨터에서 미리 이름을 바꾼 뒤** 올려주세요.
